# 🌿 Paradise Nursery - e-Plant Shopping

Paradise Nursery is a modern React-based shopping cart application for an online
plant shop. The application allows users to browse a variety of houseplants, add
them to a shopping cart, manage item quantities, and view the total cost before
checkout.

This project was developed as the final project for the **Developing Front-End
Apps with React** course on Coursera.

# ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/jahnvi-vyas/Paradise-Nursery-Shopping-Application.git
```

Navigate to the project:

```bash
cd Paradise-Nursery-Shopping-Application
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open your browser:

```
http://localhost:5173
```
